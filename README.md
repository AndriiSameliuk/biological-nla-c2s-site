# Biological NLA public explorer

This repository contains the public static companion website for the Biological Natural Language Autoencoder project. The interactive explorer visualizes recorded real-cell examples and reconstruction behavior; the technical report is included.

[Open the live interactive demo](https://andriisameliuk.github.io/biological-nla-c2s-site/) or [read the technical report](https://andriisameliuk.github.io/biological-nla-c2s-site/technical_report.html).

Implementation code and model weights are maintained separately in private repositories and require authorized access. This repository intentionally contains only public presentation artifacts. The explorer replays recorded evidence; it does not run a live transformer.
